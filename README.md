# MongoDB GUI Application

This application demonstrates a C# GUI that connects to MongoDB and manages football data for leagues, teams, matches, and more. It provides:

- Data generation with user-defined parameters.
- CRUD functionality (Create, Read, Update, Delete).
- JSON Import/Export.
- Full control over MongoDB localhost:27017.

## Features

- **Data Generator**: Dynamically generates football data (leagues, teams, players, sponsors, matches, etc.).
- **CRUD Operations**: Add, view, edit, and delete data entries.
- **MongoDB Integration**: Fully functional database system leveraging MongoDB.
- **Import/Export JSON**: Load and save data as JSON.

## Prerequisites:

- MongoDB installed locally and running at `localhost:27017`.
- .NET installed (.NET Framework or .NET Core).

## Setup:

1. Clone this repo:
```
git clone https://github.com/DEMONLIVE13/MongoDB-GUI-Application
```
2. Build the project using Visual Studio or Visual Studio Code.
3. Run `MongoDB-GUI-Application.exe`.
